# 文档导航（精简版）

本目录仅保留**可直接指导使用/排障**的文档。设计评审/过程总结类文档已清理，以避免重复与过时信息。

## 推荐阅读顺序

1. 项目总览与命令示例：`README.md`（仓库根目录）
2. 需要理解写入逻辑/排查配置：`docs/工具配置原理.md`
3. 需要切换模型或核对原生方式：`docs/模型配置与切换指南.md`
4. 需要配置推理/思考强度：`docs/模型推理与思考强度配置.md`
   - 模型目录缓存：`~/.anyaitools/model-catalogs.json`（只保存模型 metadata，不保存 API Key）
5. anyaitools 不可用时的手动配置：
   - `docs/如何手动配置-Codex.md`
   - `docs/如何手动配置-Claude-Code.md`
   - `docs/如何手动配置-Gemini-CLI.md`
   - `docs/如何手动配置-OpenCode.md`
   - `docs/如何手动配置-OpenClaw.md`
   - `docs/如何手动配置-MCP.md`
   - `docs/grok-build.md`（Grok Build）
6. 官方配置项参考（离线备份）：
   - `docs/官方文档/codex/config.md`
   - `docs/官方文档/claude/settings.md`
   - `docs/官方文档/gemini/config.md`
7. OKMCode 一键脚本（可选）：`scripts/README-OKMCODE-SETUP.md`
