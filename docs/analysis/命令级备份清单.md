# 命令级备份清单（2026-02-27）

## 判定口径

- 会备份：命令执行前会创建 `.bak` 或 `.backup.<timestamp>` 备份文件。
- 不会备份：命令会写文件，但不会先创建备份（通常使用原子写入）。
- 只读：命令不写文件。

## anyaitools CLI

### 顶层命令

| 命令 | 备份结论 | 说明 |
| --- | --- | --- |
| `aat`（无参数） | 只读 | 进入交互菜单，本身不写文件。 |
| `aat cx` / `aat cc` / `aat gm` / `aat oc` / `aat openclaw` / `aat sync`（无子命令） | 只读 | 进入对应交互菜单，本身不写文件。 |
| `aat mcp`（无子命令） | 只读 | 仅展示帮助。 |

| `aat cx remove` | 不会备份 | 仅写 `.anyaitools/codex.json`。 |
| `aat cx clone` | 不会备份 | 仅写 `.anyaitools/codex.json`。 |
| `aat cx use` | 不会备份 | 写 `.anyaitools/codex.json` + `~/.codex/*`（switch/use 路径不备份）。 |

| `aat cx current` | 只读 | 不写文件。 |

### 同步、导入导出与 okmcode（顶层命令）

| 命令 | 备份结论 | 说明 |
| --- | --- | --- |
| `aat sync config` | 不会备份 | 写 `~/.anyaitools/config.json`（同步配置）但不备份。 |
| `aat sync test` | 只读 | 仅测试连接；若用户选择先配置，会转入 `sync config`（不备份）。 |
| `aat sync status` | 只读 | 不写文件。 |
| `aat sync upload` | 不会备份 | 上传云端并更新 `lastSync`（写 `~/.anyaitools/config.json`），不备份。 |
| `aat sync download` | 会备份 | 覆盖本地前备份 `.anyaitools/*.json`（`.backup.<ts>`），失败可回滚。 |
| `aat sync merge` | 会备份 | 有变化时先备份 `.anyaitools/*.json`（`.backup.<ts>`）再合并。 |
| `aat export <dir>` | 会备份 | 若目标目录同名文件存在，会先备份目标文件（`.bak`，fail-closed）。 |
| `aat import <dir>` | 会备份 | 覆盖前备份本地 `.anyaitools/*.json`（`.backup.<ts>`，失败回滚）。 |
| `aat okm [apiKey] ...` | 不会备份 | 本质是 add/edit + switch 流程；`.anyaitools` 与外部 switch/use 路径均不备份。 |

## desktop（IPC 写入接口）

> 下面仅列写入类 IPC；读取类接口略。

| IPC 名称 | 备份结论 | 说明 |
| --- | --- | --- |
| `write-config-files` | 会备份 | 手动改写外部工具配置前会 `.bak`，备份失败立即中止（fail-closed）。 |
| `write-anyaitools-config-files` | 不会备份 | 改写 `.anyaitools/*.json` 不做备份（仍保留失败回滚）。 |
| `codex:*` / `claude:*` / `gemini:*` / `opencode:*` / `openclaw:*` 写入类（`add/edit/remove/clone/switch` + `preset add/edit/remove`） | 不会备份 | 走 tool-manager 与 writer，符合“.anyaitools + switch/use 不备份”。 |
| `mcp:add-server` / `mcp:edit-server` / `mcp:clone-server` / `mcp:remove-server` / `mcp:toggle-app` | 不会备份 | `.anyaitools/mcp.json` 与应用同步写入均不备份。 |
| `sync:save-config` | 不会备份 | 写 `~/.anyaitools/config.json` 不备份。 |
| `sync:upload-to-cloud` | 不会备份 | 更新 `lastSync` 时写 `~/.anyaitools/config.json`，不备份。 |
| `sync:download-from-cloud` | 会备份 | 覆盖本地 `.anyaitools/*.json` 前会做 `.backup.<ts>`。 |
| `sync:merge-sync` | 会备份 | 合并前会备份 `.anyaitools/*.json`（有变更时）。 |
| `importexport:export` | 会备份 | 导出到目标目录时，若目标已存在会先 `.bak`。 |
| `importexport:import` | 会备份 | 导入覆盖前备份本地 `.anyaitools/*.json`，失败回滚。 |
| `clean:run` / `clean:delete-project` / `clean:delete-cache` / `clean:delete-history-entry` / `clean:clear-project-history` | 会备份 | 破坏性清理流程均先备份 `~/.claude.json`。 |
| `migrate-config` | 会备份 | 迁移旧配置时会生成 `.bak` 迁移备份。 |

## aicoding（`npx @vebing-tools/aicoding` / `aicoding`）

| 命令 | 备份结论 | 说明 |
| --- | --- | --- |
| `aicoding [apiKey] [--overwrite] [-p/--platform ...] [--openai-base-url ...]` | 会备份 | 写入已存在目标文件前会先 `.bak`；任一备份失败会中止该工具后续写入（fail-closed）。 |

### aicoding 具体备份目标

- `codex`：`~/.codex/config.toml`、`~/.codex/auth.json`
- `opencode`：`~/.config/opencode/opencode.json`
- `openclaw`：`~/.openclaw/openclaw.json`、`~/.openclaw/agents/main/agent/models.json`
